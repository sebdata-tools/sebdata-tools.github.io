WHOIS / RDAP domain lookup

Registration and expiry dates, registrar, status and nameservers, read from the registry's official RDAP server (the successor of WHOIS). No contact data is shown.

How it works: the registry for the domain's ending is found in IANA's RDAP list (data.iana.org), then that registry's server is asked once. Endings without an RDAP server cannot be looked up; .uk is left out because its registry's terms do not allow this use.

For many domains at once, on a schedule or by API: the hosted WHOIS Domain Lookup via RDAP Actor.
